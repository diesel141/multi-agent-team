# チーム構成・ロール定義

## 階層構造

ユーザー（you）→ PM 兼 Designer（pm）→ Developer 兼 Tester（dev）× 3

## ロール定義

| ロール | 責務 |
|---|---|
| **pm** | タスク分解 / UX 仕様判断 / dev への分配 / 受入レビュー |
| **dev1** | 実装 + 自己テスト / pm へ完了報告 |
| **dev2** | 実装 + 自己テスト / pm へ完了報告 |
| **dev3** | 実装 + 自己テスト / pm へ完了報告 |

## 振り分け方針

- dev1 単独デフォルト禁止（3 並列を第一候補）
- 検証スクリプト → dev3
- CI 関連 → dev2
- 別ファイル変更 → 別 dev へ分配

## インストラクション

各ロールの詳細指示: `instructions/<role>.md`
