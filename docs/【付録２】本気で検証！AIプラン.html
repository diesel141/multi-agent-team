CLAUDE（max 5x / pro）

  • 設計・言論のやりとり（要件の壁打ち・仕様の言語化）が 7 プラン中で最も強い
  • エージェントとして長時間自走させても指示逸脱・暴走が少なく、ADD の中核に据えられる
  • max 5x なら上位モデルを常用しても制限に届かず、品質と快適さを両立できる

Codex（Chat GPT）Plus

  • 実装力は CLAUDE に近い水準で、明確な指示に対するコード生成は高速・正確
  • 設計・言論のやりとりが弱く、要件整理や方針議論の相手には不向き
  • 「設計は CLAUDE、実装は Codex」という分担が現実的

GLM pro

  • 日常的なコーディング・テスト生成では上位プランと遜色ない品質
  • 複雑な設計判断や長い議論では CLAUDE に一歩譲る
  • トークン量（CLAUDE pro の 3 倍・体感 2 倍）と性能のバランスが良く、5H 制限時の受け皿として優秀

Deepseek

  • 推論力が高く、コード品質も価格からは想像できない水準
  • プリペイドで制限なし・トークン潤沢のため、大量の試行錯誤に最適
  • 推論（思考）が長くなりがちで、応答の体感速度は上位プランに劣る場面がある

Google One

  • タスク完遂まで自走する癖が強く、放置型のワークフローでは頼れる
  • 反面、途中確認が少なくトークン消費が激しい（コスト面の弱点と表裏一体）
  • 長大なコンテキスト処理（大きなコードベースの読み込み）に強い

GitHub Copilot pro

  • エディタ内補完・スポットの修正は快適で、日常の実装速度を底上げする
  • 設計・提案は弱く、単体で ADD を回すのは難しい
  • 他プランと併用する「作業補助」ポジションが最適

📝 総評

結論：開発性能に妥協せず、最もコスパが良い組み合わせ

本検証の結果、採用する組み合わせは以下に決定した。

プラン 月額 担当領域
CLAUDE pro $22/月 設計・監視・運用（Opus / Fable）
GLM pro $18/月 実装・テスト実施・資料作成
Deepseek 利用分だけ（プリペイド） 制限時のバックアップ
合計 $40＋/月 -

運用方針

  • CLAUDE Opus や Fable に設計・監視・運用などを任せる
  • GLM に実装・テスト実施・資料作成を任せる
  • いずれかに制限がかかった場合、Deepseek で補う

選定理由

  • 設計・言論に最も強い CLAUDE と、トークン量に余裕がある GLM の分担で、性能と物量を両立できる
  • 両者の弱点である 5H 制限は、制限なしのプリペイド型 Deepseek がカバーする
  • 7 プラン並行時（￥35,862/月）と比較して、月額を約 $40＋（￥6,651＋利用分）まで圧縮できる
